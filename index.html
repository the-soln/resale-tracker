Store settings

Customers see the name, tagline, banner, about, policy, and whichever contact buttons you fill in. Buying happens by message or through the listing link on each item; the store page takes no payments.
Publishing (GitHub)
Publishing writes the catalog and photos into your repository, then GitHub rebuilds the site in about a minute. Create a fine-grained token at github.com/settings/personal-access-tokens/new with access to only this repository and the Contents: Read and write permission. The token is stored only on this device.

Add photos
